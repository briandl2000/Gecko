# core_example

A guided tour of the concrete Core systems retained from the original example:

1. Allocator statistics and labelled profiler counters.
2. Immediate and queued events, including a send from a worker job.
3. Thread IDs, yielding, and precise sleeping.
4. Parallel particle jobs and a three-stage dependency chain.
5. Every log level using Gecko's `{}` formatter.
6. Profiler diagnostics and aggregated scope statistics.

The example is headless and uses the null platform backend.
